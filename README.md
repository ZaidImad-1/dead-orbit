The galaxy has fallen. Zombie hordes have infected every sector of deep space.

## ⚡ Features

- 🚀 Smooth 60fps canvas renderer
- 🧟 5 escalating zombie waves
- ⚡ **Combo system** — chain kills for x2 x3 x4 score multiplier + screen flash
- 🪙 **Coin system** — earn coins from every kill
- 🛒 **Armory Shop** — 6 unlockable ship skins
- 🎨 Each skin changes ship emoji, bullet color & trail effect
- 🎵 Horror background music with ON/OFF toggle
- 🔊 Sound effects — shoot, hit, combo, death, level-up
- 📳 Haptic vibration feedback on mobile
- ⛶ Fullscreen mode
- 📱 Installable as phone app (PWA)
- 📵 Works offline after first load
- ⚡ Zero-delay controls using Pointer Events API

## 📱 Install

### Android (Chrome)
1. Open **[https://ZaidImad-1.github.io/dead-orbit/](https://ZaidImad-1.github.io/dead-orbit/)** in Chrome
2. Tap ⋮ menu → **Add to Home Screen**
3. Tap **Add** ✅

### iPhone (Safari)
1. Open the link in Safari
2. Tap the **Share** button
3. Tap **Add to Home Screen** → **Add** ✅

## 🛠 Tech Stack

- **React 18** — UI & game state
- **HTML5 Canvas** — 60fps game rendering
- **Web Audio API** — procedural horror music & SFX
- **Pointer Events API** — zero-delay mobile controls
- **Navigator Vibrate API** — haptic feedback
- **PWA** — manifest + offline support
